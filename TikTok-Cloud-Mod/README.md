\# TikTok Cloud Mod



iOS customization project.



\## Features



\- Cloud Mod floating menu

\- LikeColor

\- 9 selectable colors

\- Persistent color selection



\## Build



1\. Upload TikTok.ipa to repository root.

2\. Open GitHub Actions.

3\. Select TikTok Cloud Mod Build.

4\. Press Run workflow.

5\. Download TikTok-CloudMod artifact.

6\. Sign IPA using Sideloadly.



Target: arm64

Minimum iOS: 14.0
